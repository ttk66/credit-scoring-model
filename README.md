# Credit Scoring Model

Автоматизированный пайплайн разработки, тестирования, развёртывания и мониторинга модели машинного обучения для предсказания **вероятности дефолта клиента** (кредитного скоринга).

Проект содержит полный жизненный цикл ML-решения: от загрузки и обработки данных, через обучение моделей, до упаковки, развёртывания и отслеживания производительности. :contentReference[oaicite:1]{index=1}

---

## Основная идея

Кредитный скоринг — это задача оценки **кредитоспособности клиентов** на основе их истории, финансовых и демографических данных. Цель модели — определить, с какой вероятностью клиент допустит **дефолт по обязательствам** (невыполнение финансовых обязательств).

Данный репозиторий реализует:
- **обработку и подготовку данных**;
- **обучение ML-моделей**;
- **оценку качества предсказаний**;
- **CI/CD и управление экспериментами**;
- **средства развёртывания и мониторинга**. :contentReference[oaicite:3]{index=3}

## Структура репозитория:
**├── .dvc/ # Конфигурация DVC (отслеживание данных)**;

**├── .github/workflows/ # CI/CD (GitHub Actions)**;
**├──data/ # Исходные и промежуточные данные**;
**├── docker_for_random_forest/ # Dockerfile для конкретной модели/окружения**;
**├── mlruns/ # Данные экспериментов MLflow**;
**├── models/ # Сохранённые обученные модели (в данной папке будет лежать несколько NN моделей из-за зачёта)**;
**├── notebooks/ # Jupyter-ноутбуки с EDA/экспериментами**;
**├── src/ # Основной исходный код (скрипты моделей)**;
**├── tests/ # Юнит-тесты**;
**├── requirements.txt # Зависимости Python**;
**├── structure.py # пример структуры проекта**;
**├── dvc.yaml # DVC-пайплайн**;
**└── README.md**

EDA представлен в папке notebooks, скрипты для загрузки/обработки данных и обучения модели находятся в src.
Для оценки качества модели используются стандартные метрики:
Accuracy, Precision, Recall,
ROC-AUC
